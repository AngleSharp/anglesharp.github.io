# AngleSharp Videos

This is a monorepo for the AngleSharp videos. They're written in React with [Remotion](https://www.remotion.dev) and managed with npm workspaces.

```
videos/
├── shared/   # @anglesharp/video-shared: theme, animation helpers, reusable components
├── tools/         # generate-music.mjs (background music), sync-samples.mjs (tutorial code/output)
├── intro/         # @anglesharp/video-intro: "Introduction to AngleSharp" (8:00)
├── release-1-11/  # @anglesharp/video-release-1-11: "AngleSharp 1.11" release video (3:00)
└── tutorials/     # @anglesharp/video-tutorials: six tutorials (4:00–6:00), built from ../samples
```

## Getting started

```sh
cd videos
npm install

npm run studio:intro    # open the intro in Remotion Studio
npm run render:intro    # render to intro/out/introduction.mp4 (with background music)
npm run render:intro:silent  # same, without music
npm run music:intro     # regenerate intro/public/music.mp3 (needs ffmpeg, ~1 min)

npm run studio:release-1-11         # same commands for the 1.11 release video
npm run render:release-1-11
npm run render:release-1-11:silent
npm run music:release-1-11

npm run studio:tutorials            # all six tutorials (Tutorial1 … Tutorial6)
npm run render:tutorial-3           # render one tutorial to tutorials/out/tutorial-3.mp4
npm run sync:tutorials              # re-run ../samples and regenerate the code/output the tutorials show
npm run typecheck       # typecheck all workspaces
```

You can also render a single frame to check a scene:

```sh
cd intro
npx remotion still src/index.ts Extensions out/extensions.png --frame=300
```

## Shared package

`shared/` is consumed as TypeScript source, so it needs no build step. It contains:

- **Theme**: `colors`, `fonts` (Inter and JetBrains Mono via `@remotion/google-fonts`), `VIDEO` (1920×1080 @ 30 fps), and `SAFE` (the safe-area padding). The colors match the website (`v2026/src/styles.css`).
- **Animation helpers**: `progress`, `windowed`, `useEnter`, `typed`, `easeOut`, `easeInOut`.
- **Highlighting**: `tokenize` and `tokenizeLines`, a small synchronous highlighter for C#, JS, HTML and bash.
- **Components**:
  - `Background`, `LogoMark`, `Wordmark`
  - `SceneFrame`, a branded scene with a chapter label and watermark
  - `Heading`, `Accent`, `Card` (with a `compact` variant for stacking next to code), `BulletList`, `Pill`, `Code`
  - `BarCompare`, animated before/after benchmark bars with the relative change
  - `TutorialOpening`, `TutorialOutro`, `BrowserWindow`, `NetworkLog` for the tutorial series
  - `Window`, `CodeBlock` (line reveal and highlighted ranges), `Terminal` (typed commands and output)
- **Transitions**: `sceneTiming()` and `TRANSITION_FRAMES`, the default fade timing between scenes.

## Adding a new video

1. Copy `intro/` to a new folder, e.g. `videos/extensions-deep-dive/`. Remove `src/scenes/*` and `narration.md`.
2. Rename the package in its `package.json`, e.g. `@anglesharp/video-extensions-deep-dive`.
3. Add the folder to `workspaces` in `videos/package.json`, and add `studio:<name>` / `render:<name>` scripts.
4. Run `npm install` from `videos/`.
5. Build your scenes from `@anglesharp/video-shared`. If a component is useful to more than one video, move it into `shared/`.

## Conventions

- One component per scene in `src/scenes/`. Each scene is also registered as its own composition (in a `<Folder>`), so you can preview it alone in the Studio.
- Scene lengths live in `src/timeline.ts`. The total length is computed from them, minus the transition overlaps.
- Every video has a `narration.md`: the spoken text, split into blocks with a timecode and an on-screen cue each, written to be read live over the video or recorded as a voice-over.
- Background music lives in `public/music.mp3` and is generated by `tools/generate-music.mjs` (deterministic per `--seed`; set `--duration` to the video length in seconds). The composition plays it via `<Audio>` from `@remotion/media`, with `music` and `musicVolume` props so it can be muted or turned down at render time.
- Drive all animation from `useCurrentFrame()`. CSS transitions and animations don't render correctly in Remotion.
