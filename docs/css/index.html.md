## Recommended Reading Order

If you are new to AngleSharp.Css, this order gives a practical ramp-up:

1. [Getting Started](https://anglesharp.github.io/docs/css/general/basics/index.html.md) for setup and first working code.
2. [Examples](https://anglesharp.github.io/docs/css/tutorials/examples/index.html.md) for copy-paste recipes.
3. [API Documentation](https://anglesharp.github.io/docs/css/tutorials/api/index.html.md) for deeper understanding of the CSSOM model.
4. [CSSOM](https://anglesharp.github.io/docs/css/general/cssom/index.html.md) and [Core Interfaces](https://anglesharp.github.io/docs/css/general/core-interfaces/index.html.md) once you need a deeper model understanding.
5. [Supported At-Rules](https://anglesharp.github.io/docs/css/general/supported-at-rules/index.html.md) and [Supported Declarations](https://anglesharp.github.io/docs/css/general/supported-declarations/index.html.md) when checking implementation coverage and constraints.
6. [Value Model](https://anglesharp.github.io/docs/css/general/values/index.html.md) and [Render Tree Examples](https://anglesharp.github.io/docs/css/tutorials/render-tree/index.html.md) for style computation workflows.
7. [Extensibility](https://anglesharp.github.io/docs/css/general/extensibility/index.html.md) and [Provided Services](https://anglesharp.github.io/docs/css/general/provided-services/index.html.md) for custom integrations, and the [Painting API](https://anglesharp.github.io/docs/css/general/painting-api/index.html.md) for drawing `paint()` images with your own painters or scripting engine.
8. [FAQ](https://anglesharp.github.io/docs/css/tutorials/questions/index.html.md) for common pitfalls and output customization.

## What You Can Do With AngleSharp.Css

Typical use cases include:

- Parsing and validating CSS snippets from editors, CMS content, or user input.
- Inspecting and rewriting style declarations programmatically.
- Loading real HTML pages and accessing linked stylesheets through the DOM.
- Computing final values (e.g., color, width, display) for elements.
- Building tooling: linters, migration scripts, design token extractors, or static analyzers.
