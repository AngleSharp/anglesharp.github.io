## Recommended Reading Order

If you are new to AngleSharp.Browser, this order gives a practical ramp-up:

1. [Getting Started](https://anglesharp.github.io/docs/browser/general/basics/index.html.md) for setup and first working code.
2. [Examples](https://anglesharp.github.io/docs/browser/tutorials/examples/index.html.md) for copy-paste recipes.
3. [Avalonia Control](https://anglesharp.github.io/docs/browser/general/avalonia/index.html.md) if you want to show pages in a desktop application.
4. [Browser Engine](https://anglesharp.github.io/docs/browser/general/engine/index.html.md) and [Configuration](https://anglesharp.github.io/docs/browser/general/configuration/index.html.md) to understand threading, navigation and profiles.
5. [Rendering](https://anglesharp.github.io/docs/browser/general/rendering/index.html.md), [Input](https://anglesharp.github.io/docs/browser/general/input/index.html.md) and [Writing a Custom Host](https://anglesharp.github.io/docs/browser/tutorials/custom-host/index.html.md) to integrate another UI framework.
6. [API Documentation](https://anglesharp.github.io/docs/browser/tutorials/api/index.html.md) as a reference and the [FAQ](https://anglesharp.github.io/docs/browser/tutorials/questions/index.html.md) for common pitfalls.

## What You Can Do With AngleSharp.Browser

Typical use cases include:

- Taking screenshots of pages without a display, entirely in .NET.
- Driving pages in tests: clicking, typing, scrolling, and inspecting the DOM afterwards.
- Embedding a web view without a native browser dependency in an Avalonia application.
- Showing your own UI written in HTML and CSS, wired up with .NET event handlers.
- Building browser-like tools with history, profiles, multiple windows and diagnostics.
