# 🎉 AngleSharp.Css 1.0.0 Is Finally Here!

Some milestones arrive quickly. Others... take a little longer.

After **almost three years** since the last release of **AngleSharp.Css**, I'm incredibly happy to finally announce the release of **AngleSharp.Css 1.0.0**! 🚀

This release has been years in the making. In fact, it comes **more than 3.5 years after AngleSharp itself reached version 1.0.0**. During that time, many users who needed complete CSS support had to rely on preview packages while the library steadily evolved behind the scenes. It's been a long wait—but hopefully one that was worth it.

To everyone who has been using the previews, reporting bugs, suggesting improvements, or simply being patient: **thank you**. This release wouldn't have happened without your feedback and encouragement.

## A Major Milestone for the CSS Engine

Version 1.0.0 isn't just a symbolic version bump—it represents a mature and stable implementation of CSS for the AngleSharp ecosystem.

The library now offers comprehensive CSS parsing capabilities together with a complete CSS Object Model (CSSOM) and support for constructing render trees. Whether you're analyzing stylesheets, building tooling, scraping websites with accurate style information, or experimenting with rendering, AngleSharp.Css now provides a solid and stable foundation.

This release also includes plenty of work that isn't immediately visible but makes a real difference:

* 📚 Significantly improved documentation to help both new and experienced users.
* ⚡ Numerous performance improvements throughout the parsing pipeline and internal data structures.
* 🛠️ Many bug fixes and standards compliance improvements accumulated over the preview releases.

As always, there are still ideas for future enhancements, but reaching 1.0 means the API is now considered stable and ready for production use.

## The AngleSharp Ecosystem Has Matured Too

While AngleSharp.Css has been working its way toward 1.0, the rest of the ecosystem hasn't been standing still.

AngleSharp itself has grown into a mature project that is used in many production applications around the world. Along the way, the project has adopted a dedicated security reporting process, helping ensure that security issues can be handled responsibly and efficiently.

Another exciting milestone was receiving support from **HeroDevs' Open Source Sustainability Fund**. ❤️

Open source projects thrive because of their communities, and financial support like this makes it much easier to dedicate time to maintenance, improvements, documentation, and long-term stability. I'm extremely grateful for that support and for everyone who continues to believe in the project.

## What's Next?

Of course, reaching 1.0.0 doesn't mean development stops—it actually makes it easier to move even faster.

There are already several exciting milestones on the roadmap:

* 🌐 **AngleSharp.Js** reaching its own 1.0 release.
* 🕸️ **AngleSharp.Wasm** following with a stable 1.0 version.
* 🎨 A renderer built on top of AngleSharp.Css, bringing the ecosystem one step closer to a fully managed rendering pipeline.

There will also be more regular releases going forward. Now that the foundation is in place, future updates can focus on incremental improvements, new standards support, performance optimizations, and ecosystem enhancements.
