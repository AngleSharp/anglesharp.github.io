It's time for another release! I'm happy to announce that **AngleSharp 1.6.0** is now available.

While this release contains plenty of improvements to the core library itself, it's also a good opportunity to look at the bigger picture. There's been a lot of movement across the entire AngleSharp ecosystem recently, and it feels like everything is coming together nicely.

## 🚀 AngleSharp 1.6.0: A Stronger Foundation for the Ecosystem

The biggest news is undoubtedly the release of **AngleSharp.Css 1.0.0**. After years of preview releases and continuous improvements, the CSS library has finally reached its first stable milestone.

That also means the ecosystem now offers a production-ready HTML parser together with a fully mature CSS implementation—a combination many users have been waiting for.

And that's not where the story ends...

Recently, **AngleSharp.Js** has started receiving renewed attention as well. The goal is clear: bring it to its own **1.0.0** milestone and complete another important piece of the ecosystem. There's still work to do, but it's exciting to see momentum building again.

It's fair to say that the AngleSharp ecosystem is more active than it has been in quite some time. 🎉

## AngleSharp 1.6.0

Of course, this release isn't just about the surrounding projects.

AngleSharp itself continues to evolve with a focus on standards compliance, correctness, performance, and providing a pleasant API for developers building everything from web scrapers to static site generators, testing frameworks, analyzers, and rendering solutions.

Version **1.6.0** brings several meaningful improvements.

### Faster Under the Hood ⚡

Performance has always been an important goal for AngleSharp, and this release continues that trend.

A number of internal optimizations reduce overhead and improve throughput across common parsing scenarios. While many of these improvements aren't immediately visible from the outside, they contribute to making AngleSharp an even better choice for high-performance workloads.

## Smarter URL Handling

One of the more interesting additions in this release is an expansion of the `Url` class.

AngleSharp now performs much more comprehensive parsing and normalization of **IPv4** and **IPv6** addresses, following the URL specification more closely.

That includes support for various numeric representations of IPv4 addresses—including decimal, hexadecimal, octal, and mixed-digit formats—which are all normalized to their canonical representation. While these formats aren't something most developers encounter every day, supporting them correctly is an important part of standards compliance and compatibility with browser behavior.

It's one of those features that most people will never notice—but when you need it, you'll be glad it's there.

## Better CSS Selector Support

The CSS selector engine has also received additional improvements.

Selectors are at the heart of many AngleSharp use cases, and every enhancement here benefits developers working with HTML analysis, scraping, testing, document transformations, and much more.

As browser standards continue to evolve, keeping selector support robust and performant remains a priority.

## Looking Beyond AngleSharp

One particularly exciting development is a project that has started to grow just outside the AngleSharp ecosystem while relying heavily on it under the hood: [**netpack**](https://github.com/FlorianRappl/netpack).

If you haven't heard of it yet, netpack aims to bring a modern, high-performance asset bundler to the .NET world.

Unlike traditional JavaScript tooling—which typically revolves around npm, Node.js, and a collection of external tools—netpack is built entirely in **.NET**. It can certainly fit into modern web development workflows, but its real strength is that it's also available as a fully managed library.

Imagine being able to:

* understand HTML, CSS, and JavaScript assets,
* optimize and transform them,
* bundle everything together,
* and serve the results,

all without ever leaving the .NET ecosystem.

That's the vision behind netpack, and AngleSharp provides many of the standards-compliant parsing capabilities that make it possible.

The project is still taking shape, but it's already exciting to see where it's heading. If you're curious, it's definitely worth keeping an eye on.

👉 [netpack.anglevisions.com](https://netpack.anglevisions.com/)
