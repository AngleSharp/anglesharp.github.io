Latest release: AngleSharp 1.11.0

Parse the web.
The .NET way.

AngleSharp is the standards-driven engine for HTML5, CSS, SVG, MathML, and XML in .NET. Parse, query, style, script, and render documents — exactly like a browser would.

var context = BrowsingContext.New(Configuration.Default);

using AngleSharp;
using AngleSharp.Css.Dom;
using AngleSharp.Dom;

var config = Configuration.Default.WithCss();
var context = BrowsingContext.New(config);
var document = await context.OpenAsync(req => req.Content("""
    <style>.alert { color: tomato }</style>
    <p class="alert">Heads up!</p>
    """));

var p = document.QuerySelector(".alert")!;
var style = document.DefaultView!.GetComputedStyle(p);
Console.WriteLine(style.GetColor());
OutputAngleSharp.Css
rgba(255, 99, 71, 1)

Why AngleSharp

A browser engine core, as a library.

Everything you need to work with web content from C#, F#, or PowerShell — on any platform that runs .NET.

Standards-driven

Built from the WHATWG and W3C specifications. Malformed HTML is handled exactly like in evergreen browsers.

Fast by design

Streaming tokenizer, minimal allocations, and modern TFMs. Parse large documents in milliseconds.

The real DOM

The API you know from the browser: querySelector, events, mutation, serialization — fully interactive.

Selectors & LINQ

Powerful CSS selectors, XPath via AngleSharp.XPath, and LINQ on top of every node collection.

Modular ecosystem

A small, dependency-free core. Add CSS, JavaScript, XML, IO, or rendering only when you need it.

Extensible everywhere

Bring your own requester, cookie container, script engine, or service. Everything is configurable.

Modern HTML

template, picture, popovers, shadow DOM, custom elements — AngleSharp keeps up.

Forms & navigation

Fill, validate, and submit forms. Navigate between pages with a full browsing context.

Architecture

From bytes to pixels.

Every stage of the browser pipeline is a package. Pick the ones you need — they all plug into the same BrowsingContext.

  1. 01FetchAngleSharp.IoRequesters, cookies, caching
  2. 02ParseAngleSharpHTML5 tokenizer & tree builder
  3. 03DOMAngleSharpNodes, events, selectors
  4. 04StyleAngleSharp.CssCSSOM & computed styles
  5. 05ScriptAngleSharp.JsJavaScript on the DOM
  6. 06RenderAngleSharp.RendererLayout & paint
  7. 07BrowseAngleSharp.BrowserThe complete engine
