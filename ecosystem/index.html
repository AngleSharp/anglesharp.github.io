Ecosystem

The AngleSharp ecosystem

A dependency-free core with focused companion libraries. Each package plugs into the same configuration and browsing context.

Core

AngleSharp

Stablev1.11.0

HTML parser, DOM provider, CSS selector engine, and core utilities. Helpers and parsing for MIME types, URLs, source sets, and many more. Provides the extension points used by all other projects.

$ dotnet add package AngleSharp
383Mdownloads
Docs GitHub NuGet
