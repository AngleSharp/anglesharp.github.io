Community #

  • Questions & bugs — open an issue in the respective repository on GitHub.
  • Contributing — every repository contains a CONTRIBUTING.md. Small improvements to the docs are just as welcome as new features.
  • Sponsoring — the project is maintained in spare time. If AngleSharp helps you or your company, consider sponsoring the development.

.NET Foundation #

AngleSharp is a member project of the .NET Foundation. This project has adopted the code of conduct defined by the Contributor Covenant to clarify expected behavior in our community. For more information see the .NET Foundation Code of Conduct.
